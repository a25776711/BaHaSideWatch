# BaHaSideWatch

巴哈姆特動畫瘋觀看頁的「側欄全螢幕」擴充功能（Chrome / Edge / Brave，Manifest V3）。

進入後整個螢幕黑底：左側影片盡量放大，右側固定寬度（約 22% 螢幕寬，限 320～420px）貼齊螢幕右緣，
就是動畫瘋原生的「彈幕列表 / 進階設定」面板，版面類似 YouTube 直播全螢幕。

## 安裝（開發人員模式）

1. 開啟 `chrome://extensions`（Edge 為 `edge://extensions`）。
2. 右上角開啟「開發人員模式」。
3. 按「載入未封裝項目」，選擇本資料夾（含 `manifest.json` 的 `extension` 資料夾）。
4. 開啟任一動畫瘋觀看頁（`https://ani.gamer.com.tw/animeVideo.php?sn=...`），重新整理即可。

唯一權限是 `storage`（只用來記住下面的「接管原生全螢幕」開關）；不會連網、不收集資料。

## 用法與快捷鍵

| 操作 | 作用 |
| --- | --- |
| 控制列「側欄全螢幕」按鈕（在原生全螢幕鈕旁） | 進入側欄全螢幕 |
| `Shift + F` | 進入 / 離開側欄全螢幕（在輸入框打字時不會觸發） |
| `Esc` | 離開 |
| `F`、原生全螢幕鈕、影片雙擊（模式內） | 改為「離開側欄全螢幕」 |
| `Shift + C`（模式內） | 隱藏 / 顯示右側面板，隱藏時影片鋪滿 |

- 模式外（開關關閉時），網站原本的 `F`（原生全螢幕）、`T`（劇院模式）、`D`（彈幕開關）、空白鍵等行為完全不變。
- 進入時會呼叫整頁全螢幕；若瀏覽器拒絕，會退而使用「網頁全螢幕」（僅 CSS 版面鋪滿視窗），按 `Esc` 離開。
- 在模式內換集（點集數或下一集）不會重新載入頁面，側欄模式與全螢幕都會保留。
- 若在模式內重新整理頁面（F5），瀏覽器不允許自動進入真全螢幕，所以會先自動套用側欄版面，
  並提示「按 Shift+F 進入全螢幕」；按 `Shift + F` 即可升級為真全螢幕。
- 模式內仍可在影片控制列的輸入框發彈幕。

## 設定開關：原生全螢幕改為側欄模式

點瀏覽器工具列的擴充功能圖示 -> BaHaSideWatch，有一個開關「原生全螢幕改為側欄模式」（預設關閉，存於 `chrome.storage.sync`，變更立即生效、不需重新整理）。

| 開關 | 模式外按 `F` / 全螢幕鈕 / 雙擊影片 | 模式內按 `F` / 全螢幕鈕 / 雙擊影片 |
| --- | --- | --- |
| 關閉（預設） | 動畫瘋原本的全螢幕（完全不攔截） | 離開側欄全螢幕 |
| 開啟 | 進入側欄全螢幕 | 離開側欄全螢幕 |

- 控制列的「側欄全螢幕」按鈕與 `Shift + F` 不受開關影響，永遠可用；開啟時按鈕提示會顯示「F / Shift+F」。
- 若已處於原生全螢幕中，`F` / 全螢幕鈕仍照原樣用來離開全螢幕。

## 技術備註：真全螢幕下的站方樣式

整頁全螢幕時動畫瘋會替 `<body>` 加上 `fullscreen` class，站方樣式表有一條
`body.fullscreen *:not(…) { display:none !important }`（specificity 約 0,33,1）隱藏所有非白名單元素。
本擴充功能進入模式時，在右側面板（`section.player > .subtitle`）掛上該白名單內的 class `toast-top-center`
（連同全部子孫一起豁免，站方原本的 display、分頁切換仍照站方運作；該 class 帶來的 top/right/width 已被 `content.css` 以 `!important` 覆寫），
離開時移除。不修改、不監聽站方的 `body` class。

## 除錯

在該頁的開發者工具 Console 執行 `localStorage.setItem('bsw-debug-nofs','1')` 可跳過 requestFullscreen，
僅測試網頁全螢幕退路版面；`localStorage.removeItem('bsw-debug-nofs')` 還原。

## 檔案

- `manifest.json`：MV3 設定，只在動畫瘋觀看頁注入；權限 `storage`；工具列 popup。
- `content.js`：按鈕、快捷鍵、進出模式邏輯、讀取並監聽設定（`DEFAULTS` 新增欄位即可擴充設定）。
- `popup.html` / `popup.js`：設定開關介面（支援深色模式）。
- `content.css`：所有版面樣式，皆掛在 `html.bsw-active` 下（class 前綴 `bsw-`）；
  擴充功能不搬動任何 DOM，離開時移除 class 即完全還原。

## 已知限制

- 控制列按鈕在播放廣告期間會隨站方一起隱藏；請用 `Shift + F`。
- 右側面板為動畫瘋原生彈幕列表，不會像 YouTube 聊天室那樣隨播放時間自動冒出新訊息。
